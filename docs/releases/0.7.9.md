# 鉴翎 0.7.9 发布说明

2026-11-24 定版。数据库 schema 为 13，预处理版本为 12，桌面运行时为 Electron 45.4.1（Chromium 156 / Node 24.22）。[完整更新日志](../../CHANGELOG.md) · [GitHub Releases](https://github.com/wlfcss/PlumeLens/releases)

> **系统要求变化**：macOS 最低系统版本提升至 **macOS 14.0（Sonoma）及以上**（Apple 芯片，用于支持 PyTorch 2.14.x MPS 与 CoreML 5+ `MLProgram` 加速）；macOS 13 用户请继续使用 [0.7.8](./0.7.8.md)。

## 主要变化

- **Apple Silicon 推理大幅提速**：CoreML 全模型切换为 `MLProgram` + 按 ORT 版本隔离的持久化编译缓存（二次冷启 4.5s → ~1.5s，自动清理旧版本缓存目录）；`SpeciesClassifier` 预处理移出锁并改为周期清理 MPS 缓存；新增 macOS 自适应并发、`uint8` 惰性图像管线与未变更原片 SHA-256 复用，M5 Max 实测常规鸟图吞吐提升 **+65%–75%**（最高 ~390 张/分），24 MP 大图提升 **+59%**。
- **桌面运行时与全量依赖升级**：Electron `41.6.0 → 45.4.1`（异步 `safeStorage` 自动重加密、独立导入/导出路径记忆、`esbuild` 压缩）；升级 `pillow 13.0.0`、`rawpy 0.28.0`（LibRaw 0.22.2，扩展新机身 RAW/DNG 1.7）、`onnxruntime 1.32.0`、`torch 2.14.1`、`transformers 5.24.0`、`fastapi 0.165.0`、`echarts 6.1.0`、`react 19.3.1` 等依赖，OSV 复扫 Python 73 包与前端生产依赖均 **0 漏洞**。
- **选片、复核与导出增强**：深度复核新增 A/B 并排对照与档位原因解释；导出新增 Lightroom 内置预设与自定义预设管理；统一连拍排序与组内名次；拆离 1,591 种鸟类百科正文为按需 chunk，首屏主 bundle 从 4.2 MB 降至 **1.36 MB（-68%）**，后端新增批量水合、分页选片与 `compact-v1` 紧凑摘要流。
- **历史版本原地升级兼容**：完整保留已有 SQLite 图库、历史分析结果、人工评级、人工物种修正与加密配置；升级后对已有文件夹点击「开始分析」默认跳过已有有效分析结果的照片，仅分析新增或变更原片（显式重新分析才按新引擎全量重跑）。
- **全栈审计与 UI/UX 修复**：移除向渲染层暴露 Bearer Token 的 `engineSseUrl`、收紧导航与 IPC 校验、修复多处后端并发/关闭/缓存/导出边界 bug，修复首页纵向滚动与底栏脱离、1280px 宽度裁切及原生 `<dialog>` 迁移。
- **CI 与自动化测试体系重构**：新增独立 `ci.yml`（含 Web Playwright E2E）与协同发版 `release.yml`（统一产出双端 SHA-256 校验表）；macOS CI 改为直接挂载最终 DMG 执行跨平台打包端到端冒烟验证，补齐后端核心调度与恢复单测并清理无意义/硬编码路径用例。
