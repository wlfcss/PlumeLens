# 鉴翎 0.7.9 发布说明

2026-11-25 定版。数据库 schema 为 **14**，预处理版本为 12，桌面运行时为 Electron 45.4.1（Chromium 156 / Node 24.22）。[完整更新日志](../../CHANGELOG.md) · [GitHub Releases](https://github.com/wlfcss/PlumeLens/releases)

> **系统要求变化**：macOS 最低系统版本提升至 **macOS 14.0（Sonoma）及以上**（Apple 芯片，用于支持 PyTorch 2.14.x MPS 与 CoreML 5+ `MLProgram` 加速）；macOS 13 用户请继续使用 [0.7.8](./0.7.8.md)。

## 主要变化

- **客户端日志与诊断模块**：首次打开应用提供中文知情同意弹窗（未同意不落盘）；设置弹窗升级为左侧四分栏并新增「日志与诊断」分栏，支持无需重启引擎热开关日志、单向 HMAC 匿名设备标识、完整硬件配置画像（程序盘/缓存盘、CPU、内存、GPU）、各任务节点耗时与匿名图片特征记录，以及一键导出脱敏 ZIP 诊断包（含中文 `SUMMARY.txt` 速览）。
- **Apple Silicon 与全链路推理/内存大幅提速**：CoreML 全模型切换为 `MLProgram` + 按 ORT 版本隔离的持久化编译缓存（二次冷启 4.5s → ~1.5s，自动清理旧版本缓存目录）；RAW 解码改用纯 NumPy `orient_array()` 原地转正，峰值内存降低 **50%+**；`SpeciesClassifier` 加载期融合 48 层 LoRA 权重并新增多鸟 `classify_batch()` 批量推理，YOLO CPU 回退模型改为按需懒加载（常驻内存省 ~300 MB）；M5 Max 实测常规鸟图吞吐提升 **+65%–75%**（最高 ~390 张/分），24 MP 大图提升 **+59%**。
- **SQLite Schema v14 与大库并发优化**：补充 7 条高频复合/部分索引、64 MB 页缓存、256 MB `mmap` 与 4 连接有界 `query_only=ON` 只读连接池；队列批量入队改用 500 条分块集合化 SQL；删库联动取消活跃分析与导出任务，按库串行化 `pause`/`resume`/`cancel`；打通跨 Electron preload 的真实 `AbortSignal` 取消与 SSE 指数退避重连；选片网格去除 1920px 预览图请求、升级有界 LRU 缓存并消除 $O(K^2)$ 查重。
- **桌面运行时与全量依赖升级**：Electron `41.6.0 → 45.4.1`（异步 `safeStorage` 自动重加密、独立导入/导出路径记忆、`esbuild` 压缩）；升级 `pillow 13.0.0`、`rawpy 0.28.0`（LibRaw 0.22.2，扩展新机身 RAW/DNG 1.7）、`onnxruntime 1.32.0`、`torch 2.14.1`、`transformers 5.24.0`、`fastapi 0.165.0`、`echarts 6.1.0`、`react 19.3.1` 等依赖，OSV 复扫 Python 73 包与前端生产依赖均 **0 漏洞**。
- **选片、复核、导出与包体拆解**：深度复核新增 A/B 并排对照与档位原因解释；导出新增 Lightroom 内置预设与自定义预设管理；统一连拍排序与组内名次；拆离 1,591 种鸟类百科正文并配置 `manualChunks` 拆分第三方依赖，首屏主入口由 4.2 MB → 1.37 MB 进一步缩减至 **756 kB**；新增 `shared/ipc.ts` 统一契约并模块化拆分 `electron/main.ts` 与 `engine/services/analysis_worker.py`。
- **历史版本原地升级兼容**：完整保留已有 SQLite 图库、历史分析结果、人工评级、人工物种修正与加密配置；升级后对已有文件夹点击「开始分析」默认跳过已有有效分析结果的照片，仅分析新增或变更原片（显式重新分析才按新引擎全量重跑）。
- **全栈安全加固与 CI/打包防回归**：缓存版本切换为显式 31 字段白名单，修复 Windows 内存限流死锁，加载物种权重前校验 manifest；收紧全量 IPC `senderFrame === mainFrame`、拦截 macOS 可执行应用包、移除 macOS 权限配置中的 `allow-dyld-environment-variables`、系统探测改用绝对路径、脱敏正则改写为严格线性时间语法、后端鉴权重构为纯 ASGI 中间件且生产态禁用查询参数令牌；修复 `plumelens-engine.spec` 噪声清理冲突，PR CI 纳入 `npm run build` 验证，实包冒烟测试加强真实检出与分档断言。
