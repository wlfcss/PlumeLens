## 变化与验证

- Windows 首次提供 x64 便携包。改进高 DPI 和中文界面、短路径下的缩略图访问、RAW 预览解码和内存紧张时的并发控制。支持在兼容的 AMD 设备上准备检测缓存。[更新日志](../../CHANGELOG.md)
- macOS 标签构建验证模型清单、镜像内应用的代码签名与 Finder 布局，并通过 6 项打包应用冷启动和历史恢复测试。[macOS 标签构建](https://github.com/wlfcss/PlumeLens/actions/runs/44375248910)
- Windows 标签构建逐文件核对 ZIP 与便携目录，并在新的托管运行器上解压测试冷启动、分析、缩略图、导出和历史恢复。该流程使用 CPU。RX 7900 XTX 的 AMD 实机数据记录在 11 月 18 日的验证报告中。[Windows 标签构建](https://github.com/wlfcss/PlumeLens/actions/runs/44375248655) · [实机验证](../../WINDOWS.md)
